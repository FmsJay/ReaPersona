# Themes the styles use

ReaPersona ships no themes. They belong to their authors, and most come with no licence to redistribute them. Download each from its author, then drop it in REAPER's `ColorThemes` folder or use **Themes > Add a theme…** in ReaPersona.

A style uses the first of its themes you have. When you have more than one, you pick between them in the style's Theme list.

Where to look:

- **[REAPER Stash](https://stash.reaper.fm/tag/Themes):** search the name below. Almost all of these live there.
- **ReaPack:** Extensions > ReaPack > Browse packages, filtered to themes (the ReaTeam Themes repository).
- **[Cockos forum, Themes](https://forum.cockos.com/forumdisplay.php?f=21):** authors post new versions here.
- **[Reapertips](https://www.reapertips.com/):** the Reapertips theme.

| Style | Themes, in the order a style tries them |
|---|---|
| Base REAPER | Default_7.0, Default_6.0 (both come with REAPER) |
| Reapertips | Reapertips Theme (ReaperTips v1.95a Dark; ReaPersona keeps a copy named "Reapertips Theme (base)" so its default settings stay apart from yours), Reapertips Theme – Purple |
| Pro Tools | ProTools2020, PRO TOOLS GOLD 2026, ProTools 12.5_MC-edit |
| Logic Pro | I Logic V2 Public, FLogic, CLogic |
| Ableton Live | ReAbleton, Live, Reaper4Live |
| FL Studio | FruityCocktail |
| Cubase | CubeXR, CubeX, CubeXD, CubeXRD, Cube6, Cube6R, Cube6D, Cube6RD (the CubicPack3 packs), Reaper Cubase 2 |
| Studio One | HYDRA, CSIX-BASIC (CONCEPT SIX: personal use only) |
| Bitwig Studio | Reapertips Theme – Purple, INQUASAR DARK MATTER v.1.0, CSIX-BASIC (no theme imitates Bitwig yet) |

Toolbars: the Cubase and Logic styles use the toolbar sets from CubicPack3 (`CubeX_Toolbar1`, `CubeX_PianoRollToolbar`) and CLogic (`CFLogic_Toolbar1`, `CFLogic_PianoRollToolbar`). Copy their `.ReaperMenu` files into ReaPersona's `toolbars` folder, then run `install_shortcuts.py`.

Made a theme with **Merge** or **Adjust**? It's yours to use, but share it only with its source themes' authors' agreement.
